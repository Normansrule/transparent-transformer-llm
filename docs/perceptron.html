Each picture is one neuron's 784 weights laid back out as an image. Blue pixels push the neuron on, red pixels push it off. Notice they are not neat strokes or loops, exactly as in the famous video: the network found its own messy features that work. Click one to inspect it.

What is happening, one step at a time

  1. Every pixel is an input neuron. Its activation is a number from 0 (black) to 1 (white). 784 of them.
  2. Each neuron in the next layer is a perceptron: it multiplies every input by its own weight (the lines: blue positive, red negative), adds them up, adds a bias, and squashes the total into 0..1 with the sigmoid σ(z) = 1 / (1 + e^-z).
  3. The second hidden layer does the same thing to the first layer's 16 activations. Layers build on layers.
  4. The 10 outputs are scored the same way; softmax turns them into probabilities. The brightest wins.
  5. Where did the 13,002 numbers come from? Backpropagation, the same hand-written calculus as stage 7, run over 30,000 generated digits. Code: perceptron/train_digits.py.
  6. The connection to the language model: every transformer block contains exactly this, a Multi-Layer Perceptron (MLP), 64 → 256 → 64 with a smoother switch (GELU) in place of the sigmoid. See it lit up on the real prompt at step 7.
